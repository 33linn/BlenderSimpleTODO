# ToDo List

[日本語](README_JA.md)

A ToDo list you can manage inside Blender.

Available in English or Japanese.

## Location

3D Viewport > Sidebar (`N`) > View > ToDo List

## Features

- Select **+**, enter the text, then select **Add**.
- Check a ToDo when it is complete.
- Switch the display between **Incomplete Only** and **All**.
- The ToDo list is stored inside the `.blend` file.
