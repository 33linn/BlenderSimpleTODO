# ToDo List

[English](README.md)

Blenderの中で管理できるToDoリストです。

英語または日本語表示に対応しています。

## 場所

3Dビューポート > サイドバー（`N`）> ビュー > ToDoリスト

## 機能

- 「＋」を選び、内容を入力して「追加」ボタンで登録します。
- 完了したToDoにチェックを入れます。
- 「未完了のみ」と「すべて」で表示を切り替えます。
- ToDoリストは`.blend`ファイル内に保存されます。
